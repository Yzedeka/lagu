# Keyboard Shortcuts

Press **?** anywhere to see this list inside the app.

## Playback

| Keys | Action |
| --- | --- |
| `Space` | Play / pause |
| `→` | Seek forward 5s |
| `←` | Seek back 5s |
| `Ctrl` + `→` | Next track |
| `Ctrl` + `←` | Previous track |
| `↑` | Volume up |
| `↓` | Volume down |
| `M` | Mute / unmute |
| `S` | Toggle shuffle |
| `R` | Cycle repeat |

## Interface

| Keys | Action |
| --- | --- |
| `L` | Toggle lyrics |
| `Q` | Toggle queue |
| `B` | Toggle sidebar |
| `F` | Fullscreen now playing |
| `0` | Now Playing |
| `1` | Library |
| `2` | Albums |
| `3` | Artists |
| `4` | Folders |
| `Ctrl` + `,` | Settings |
| `Ctrl` + `=` | Zoom in |
| `Ctrl` + `-` | Zoom out |
| `Ctrl` + `0` | Reset zoom |
| `?` | Shortcut help |
| `Esc` | Exit fullscreen / close dialogs |

Shortcuts are ignored while you are typing in a text field.
