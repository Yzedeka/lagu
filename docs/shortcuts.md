# Keyboard Shortcuts

Press **?** anywhere to see this list inside the app. Shortcuts are ignored
while you are typing in a text field.

Every action below can be **rebound** in **Settings → Keybinds**: click a
binding, press the key you want (**Esc** cancels), or **Reset keybinds** to go
back to the defaults. The help overlay always shows your current keys.

## Playback

| Default | Action |
| --- | --- |
| `Space` | Play / pause |
| `N` | Next track |
| `P` | Previous track |
| `→` | Seek forward 5s |
| `←` | Seek back 5s |
| `↑` | Volume up |
| `↓` | Volume down |
| `M` | Mute / unmute |
| `S` | Toggle shuffle |
| `R` | Cycle repeat |

## Interface

| Default | Action |
| --- | --- |
| `L` | Toggle lyrics |
| `Q` | Toggle queue |
| `B` | Toggle sidebar |
| `F` | Fullscreen now playing |
| `?` | Shortcut help |
| `Esc` | Exit fullscreen / close dialogs |

## Navigation

| Default | Action |
| --- | --- |
| `0` | Now Playing |
| `1` | Library |
| `2` | Albums |
| `3` | Artists |
| `4` | Folders |

## Fixed

These are not rebindable:

| Keys | Action |
| --- | --- |
| `Ctrl` + `,` | Settings |
| `Ctrl` + `=` | Zoom in |
| `Ctrl` + `-` | Zoom out |
| `Ctrl` + `0` | Reset zoom |
| `Ctrl` + `→` / `Ctrl` + `←` | Next / previous track |
